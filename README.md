# Agent — голосовой ИИ-ассистент на Android с моделью на устройстве

Чат-приложение, в котором **Gemma 4 E2B** работает прямо на телефоне (через LiteRT-LM): понимает
текст, голос, фото и видео, помнит разговор и умеет вызывать инструменты: телефона, внешних
MCP-серверов и Android-агента, который кликает по экрану.

Android 9+ (minSdk 28), только arm64. Нужно около 3 ГБ свободного места и желательно 8 ГБ памяти.

## Статус

Проект экспериментальный, собирается через GitHub Actions и проверяется на Samsung S10+.

Проверено на телефоне: чат с голосом и фото, склеенный контекст, сжатие контекста, фонарик,
таймер, будильник, прослушивание по имени, постоянная подпись APK.

Написано, но на телефоне не проверено или проверено не до конца: подключение MCP и Android-агента,
подтверждения опасных действий, окно контекста больше 4096 токенов, вызов инструментов через
`OpenApiTool`. Вызовы инструментов зависят от версии LiteRT-LM (см. «Известные проблемы»).

## Сборка

1. Залейте проект в репозиторий. Workflow `.github/workflows/build.yml` соберёт debug-APK:
   Actions → последний запуск → Artifacts → `agent-debug-apk`.
2. APK подписывается постоянным ключом `debug.keystore` из корня репозитория, поэтому новые
   версии ставятся поверх старых, модель при этом не удаляется. Ключ с паролем `android`
   по сути открытый: репозиторий лучше сделать приватным, а в Google Play с таким ключом
   публиковать нельзя.
3. Локально: Android Studio или `gradle assembleDebug` (Gradle 8.7, JDK 17).
4. Версия LiteRT-LM закреплена в `app/build.gradle.kts` (`litertVersion`) и показывается в
   приложении: Настройки → Модель и инструменты.

## Первый запуск

1. Установите APK, дайте разрешения на микрофон и уведомления.
2. Настройки → Модель и инструменты → «Скачать модель» (~2,6 ГБ, лучше по Wi-Fi, докачка
   после обрыва, проверка SHA-256). Дождитесь статуса «Модель: готово (окно N ток.)».
3. На главном экране нажмите «Отключить экономию батареи» в настройках (иначе система
   останавливает службу), на Samsung добавьте приложение в «не ограничивать».
4. Модель распознавания речи Vosk (45 МБ) скачается сама при первом голосовом сообщении.

## Как пользоваться

Главный экран — чат: пузырь пользователя, ответы, серые строки вызовов инструментов, фото и
кадры видео. Внизу: поле ввода, «+» (фото, видео, галерея), главная кнопка и корзина
(очистить чат с подтверждением).

Активация (Настройки → Активация):
- **По кнопке.** Главная кнопка — микрофон, после нажатия превращается в красный стоп.
- **По имени.** Вместо кнопки индикатор уровня сигнала. Приложение слушает всегда и реагирует
  на имя, которое вы вписали (нечёткое сравнение, офлайн-распознавание Vosk). Нажатие на
  индикатор включает и выключает слушание. Режим нужно включать вручную при открытом
  приложении (ограничение Android 12+), после перезагрузки он сам не поднимется.

Голосовое сообщение уходит в модель как звук, а в чате показывается его расшифровка.

## Контекст

Чат склеенный: история (текст, картинки, кадры видео, расшифровки) хранится в приложении, диалог
модели пересобирается из неё. Чистится только кнопкой или при превышении лимита. Стратегии
(Настройки → Контекст чата): убирать начало или убирать середину. Убранное остаётся в чате
бледным, но модель его не видит.

Окно модели задаётся при загрузке (`maxNumTokens`). По умолчанию выбирается по объёму памяти
(на 8 ГБ это 32768). Можно вписать больше (до 131072): если памяти не хватит, приложение само
пробует вдвое меньше, вплоть до 4096. Количество токенов в оценках приблизительное.

## Инструменты

- **Встроенные** (12 штук): дата и время, заряд, будильник, таймер, фонарик, громкость,
  запуск приложения, ссылка, поиск, набор номера, черновик SMS, событие календаря. Две
  реализации: `OpenAPI` (по умолчанию) и `Kotlin` (Настройки → Модель и инструменты).
- **MCP-серверы и Android-агент** (Настройки → MCP-серверы). Конфигурация в JSON:

```json
{
  "mcpServers": {
    "phone": {
      "url": "http://127.0.0.1:8745",
      "headers": { "X-Auth-Token": "ТОКЕН_С_ЭКРАНА_АГЕНТА" }
    }
  }
}
```

  Клиент сам определяет протокол: Android-агент (REST, порт 8745), MCP 2026-07-28 (без сессий),
  MCP 2025-03-26 … 2025-11-25 (сессия), устаревший HTTP+SSE (2024-11-05). Локальные серверы,
  которые запускаются через `npx` или `uvx`, на телефоне не работают, нужны удалённые по HTTP.
  Кнопка «Разведка» показывает, что отвечает адрес сервера.

Для каждого инструмента задан уровень риска: **чтение** и **действие** выполняются сразу,
**опасные** (SMS, звонок, контакты, запись и удаление файлов, `su`, HTTP-запрос, закрытие
приложений) перед выполнением присылают уведомление «Да / Нет» (60 секунд, молчание — отказ).
Тапы и ввод текста подтверждений не требуют. Результаты внешних инструментов помечаются как
данные, а не команды, но защитой от внедрения инструкций это не является.

По умолчанию включено только то, что нужно для управления экраном. Вручную можно включить
всё (до 80), но чем больше инструментов, тем хуже маленькая модель выбирает и тем больше
контекста занимают описания.

## Диагностика

- Падения показываются в чате при следующем запуске серой записью «💥» (исключение, нативный
  сбой с фрагментами дампа, нехватка памяти) и «📜» с логами. Долгое нажатие на сообщение
  копирует его текст.
- В Настройки → MCP: «Проверить и загрузить» показывает для каждого сервера выбранный протокол
  или ход попыток подключения.
- В Actions шаг «Show resolved versions» выводит версии библиотек в Annotations.

## Известные проблемы

- Вызовы инструментов зависят от версии LiteRT-LM: часть версий падает на классе Java 21
  (`SwitchBootstraps`), которого нет на Android. Для этого версия закреплена (0.18.1). Если
  падает, пробуйте переключатель OpenAPI / Kotlin и другую версию (`litertVersion` в Gradle).
- Скриншот от агента попадает в чат, но модель видит его только в следующем сообщении.
- Не сделано: события SMS и звонков с активацией модели, камеры по ссылке и задачи по
  расписанию, фоновое слушание после перезагрузки, подтверждение кликов.

## Обновление проекта

```bash
cd ~/llm-android && git pull
unzip -o ~/storage/downloads/agent-mcp.zip      # внутри папка app/
git add -A && git commit -m "update" && git push
```

## Структура

| Файл | Назначение |
|---|---|
| `ChatActivity.kt`, `SettingsActivity.kt` | главный экран и настройки |
| `Chat.kt` | история, подсчёт токенов, сжатие контекста, обмен с моделью |
| `ModelHost.kt` | движок LiteRT-LM, окно, сборка диалога |
| `Tools.kt`, `PhoneTools.kt` | встроенные инструменты |
| `McpClient.kt`, `McpManager.kt`, `AgentCatalog.kt` | внешние серверы и Android-агент |
| `Confirm.kt` | подтверждение опасных действий |
| `ListenService.kt`, `Voice.kt`, `Stt.kt`, `VoskModel.kt` | голос и активация по имени |
| `AgentService.kt`, `Notifs.kt` | служба, скачивание модели, уведомление |
| `MediaUtil.kt`, `CrashLog.kt`, `Downloader.kt` | фото и видео, журнал падений, загрузка |
| `assets/android_agent_tools.json` | каталог инструментов Android-агента |
